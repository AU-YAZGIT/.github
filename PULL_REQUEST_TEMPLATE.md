## Kontrol listesi

**Genel**
- [ ] [Katkı Rehberi](https://github.com/AU-YAZGIT/.github/blob/main/CONTRIBUTING.md)'ni okudum.
- [ ] PR başlığı Conventional Commits biçiminde (`docs: katkı rehberini güncelle`).
- [ ] PR tek bir konuyu ele alıyor.
- [ ] Değişikliklerimi güncel `main` ile uyumlu hale getirdim.

**İçerik ve güvenlik**
- [ ] İçerik benim hazırladığım veya kaynağı belirtilmiş içeriktir.
- [ ] Taranmış kitap sayfası, izinsiz ders slaytı veya sınav materyali yok.
- [ ] Başkasına ait kişisel bilgi yok.
- [ ] Parola, API anahtarı, token gibi gizli bilgi yok.
- [ ] Katkımın, deponun `LICENSE` dosyasındaki lisansla yayımlanmasını kabul ediyorum.

**Yapay zeka kullanımı**
- [ ] Yapay zeka kullanmadım.
- [ ] Yapay zeka kullandım, içeriği kendim doğruladım ve düzenledim. (Nasıl kullandığını aşağıya yaz.)
